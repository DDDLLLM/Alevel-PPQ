## 如何复现

在项目目录：

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python scripts/acceptance.py
```

最后一个命令需要自己的题库已有真实 `9700_m16_qp_12.pdf` 和对应 MS，内部使用临时数据库。

浏览器回归需要 Node + Playwright（仅开发测试需要，日常运行不需要）：

```bash
npm ci
npx playwright install chromium
```

`tests/browser_acceptance.cjs` 用独立空数据库服务，加上 `REAL_PDF_DIR` 指向上述两份真实文件，验证上传和去重。服务器地址通过 `TEST_URL` 设置；系统 Chromium 可用 `CHROMIUM_PATH` 设置。

`tests/reader_browser.cjs` 使用开发样本数据库的隔离备份，依赖其中真实文件 ID 296（s19 QP21）、279（s19 MS21）、70（w16 QP23），默认服务 `http://127.0.0.1:9702`。不能拿其他题库的同数字 ID 冒充这些文件。初次验证 OCR 坐标时，该隔离副本第 70 文件第 9 页没有坐标缓存；后续运行可以复用缓存。该脚本会临时保存并撤销人工关系，只对隔离备份运行，不对个人主库运行。

## 尚需人工处理与验证边界

- 旧式非表格 MS、扫描 MS、题号不清、边界校验未通过：目前回退到关联 MS、卷内搜索和人工范围修正。**打开关联 MS 不算已定位答案。**
- 旧人工修正只提供 MS 页码时，保留页码与人工状态，但整题复制需进一步确定范围。
- 自动题号和 OCR 并未逐份人工审校。含公式、特殊符号、图内旋转文字或复杂排版的复制结果可能需要整理。图表保留在原 PDF 视觉页面。
- 本次真实样本来自开发环境的 2016–2019 文件；用户电脑上已下载的 2022–2026 PDF 不在这个执行环境，因此**没有冒称逐份验收了用户电脑的 2022–2026 题库**。功能不限制这些年份，需在更新后用自己常用试卷抽查。
- Windows/macOS 真机本次不可用：兼容原 Python 路径、启动入口、SQLite 与 Tesseract 工作流，并提供逐步更新说明；未冒称做了真机浏览器验收。
- 没有公开部署网站或上传私人 PDF/数据库。收藏、章节标签、Chapter Test 按用户要求留待后续。
